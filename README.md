# Moj Srpski

Приложение для самостоятельного изучения сербского языка (латиница), интерфейс на русском языке.

## Первая версия
- Главная страница и локальный прогресс
- Карточки базовой лексики с озвучиванием через Speech Synthesis
- Сохранённые слова (localStorage)
- Первый урок грамматики: личные местоимения и глагол **biti**
- Тест на лексику и базовую грамматику
- Учебный диалог с сербским собеседником и русскими подсказками
- PWA manifest и service worker для установки и офлайн-оболочки

## Запуск
Откройте сайт через GitHub Pages или любой статический веб-сервер. Приложение не требует сборки и зависимостей.

## GitHub Pages
В настройках репозитория выберите **Settings → Pages → Deploy from a branch → main → /(root)**.

Данные прогресса сохраняются локально в браузере на этом устройстве. Диалог в v1 работает по заранее заданным учебным сценариям, это не подключённая AI-модель.
